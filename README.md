# Crowdfunding Analytics & Enterprise CRM API

High-performance FastAPI engine providing LTV analytics, 360° donor profiles, classification rules, and dataset management.

## Stack Overview
- **Backend Hosting**: Hugging Face Spaces (Docker Engine, 16GB RAM)
- **Frontend Hosting**: Vercel (React 18 + Vite SPA)
- **Database**: Supabase Cloud PostgreSQL
- **CI/CD**: GitHub Actions Pipeline
